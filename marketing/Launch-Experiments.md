## Organic distribution

The guides describe complete jobs, provide concrete examples and link to independent working tools. The catalog guide includes a clean starter file and a deliberate repair exercise. They are included in the sitemap and directory without being counted as extra products. The applications export artifacts that a real recipient can open, giving distribution a useful reason. No automatic messages, community promotion or fabricated recommendations are part of this plan.

Use the existing public GitHub source and exact live product addresses when a real discussion calls for them. A shared review record or complete field report should be shared by its actual author with the intended recipient, not broadcast as an advertisement. Private user documents must not be repurposed into promotional examples.

## Paid discovery preparation

`search-keywords.csv` is a one-column Keyword Planner input, not a campaign import or a demand report. The official [Keyword Planner instructions](https://support.google.com/google-ads/answer/7337243/use-keyword-planner?hl=en) describe using keyword/website seeds and forecast input; actual account forecasts are still required before choosing bids. No search volumes, click prices or projected sales have been invented here.

Keep separate product ad groups and land visitors on the page that matches their task. Proposed exclusions are jobs, salaries, agency services, physical product purchases and unrelated free-stock-photo searches. These are targeting hypotheses that need actual search-term evidence. English copy targets an international audience; no Turkey-only location setting is assumed.

Account activation and an explicit spending budget are prerequisites for any media purchase. No budget has been authorized or charged. Until actual retention and paid value can be measured, a page view is not a reason to scale acquisition spending.

## Measurement definitions

Distinguish opening a guide, launching an app, requesting an export, completing a useful task, returning and receiving a verified paid subscription. A click on Download alone does not prove that the file was retained or useful. These are proposed measurement definitions; the site does not currently claim to have collected them. Cloudflare analytics creation was separately blocked by the available token's permissions, as recorded in `docs/Web-Analytics-Access.md`.

When a real Google Ads account is connected, implement its actual conversion action/tag configuration before reporting conversions. Google's [conversion setup](https://developers.google.com/google-ads/api/docs/conversions/categories) distinguishes the conversion action from the required tag snippets. Its [goal documentation](https://developers.google.com/google-ads/api/docs/conversions/goals/overview) distinguishes primary actions used for bidding from secondary observation. A page view should remain a diagnostic event rather than being presented as paid-member acquisition. Provider-signed, reconciled subscription state is the existing source of truth for paid entitlement.

## Revenue placement

AdSense or another approved publisher network earns from eligible public content when configured and approved; it does not purchase visitors. Public guides have optional network-ad eligibility. The three private workspace applications disable third-party ads. Their free local workflow demonstrates the product; actual membership offers larger shared cloud allowances, collaboration limits and stored history where that service is implemented. Billing-provider flags and the advertising page report real configuration state.

Evaluate each channel using observed useful work, return use and net collected subscription/ad revenue against actual acquisition cost. There is no current customer count, return rate or income amount to substitute into that calculation.
