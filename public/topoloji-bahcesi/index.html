Garden rules

Red branches cross. Drag the nodes to remove every crossing. Nodes must not overlap, and edges cannot pass through unrelated nodes.

Every garden is scrambled from a known valid layout. Other valid layouts also count.

Keyboard controls

Choose a node below, then move it 10 units with the arrow keys. Selecting a node does not count as a move.

Score: 2000 − moves × 5 − seconds × 2 − plan views × 150.

The plan shows faint valid node positions for 5 seconds. A shared link reproduces the graph and starting positions. This game runs locally.
