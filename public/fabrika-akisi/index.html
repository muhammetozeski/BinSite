Help

Plates and gears compete for the same ingots. Pause one line to supply another, and consider the balance before buying more machines.

Saving and rules

This is a local simulation with fictional credits. Progress stays in this browser. Production stops when the page closes, and long background pauses are skipped.

The price increases for each machine of the same type. Buy up to eight of each. Simulation speed affects every line equally.
