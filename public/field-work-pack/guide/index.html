Finish a work order

Choose a checklist, record the answers and photos, then create a handoff report.

Open Field Work Pack

  1. Choose or edit a checklist

    Open Checklist library to adapt one of eight starters, or choose New checklist. Add confirmations, measurements or photos. Mark the items needed before review, then choose Save checklist.

  2. Create the order

    In Work orders, enter a title, choose the checklist and select Create work order. Later library changes do not alter this order's checklist.

  3. Record the work

    Select Start work. Fill the checks, numbers and photos; View missing items shows what remains. Use a dot for decimals. A range includes both endpoints, and zero is different from an empty answer.

    Example handover: record six cases, check the accessories and attach a packing photo. The count alone does not complete the other two items.

  4. Review, then complete

    Choose Request review after filling the requirements, then Complete reviewed order. Use Reopen for changes before editing reviewed work; its answers remain and need another review.

  5. Save the handoff

    Use Save report or Print report. Unfinished work is marked Draft. Save order file keeps just this job. For the whole workspace and its photos, open Project files and offline use and choose Save project file.

Sharing, backups and offline use

In Sharing, invite viewers or editors. Everyone invited can read the shared details and notes. Photos are not saved online: reconnect the originals on another device or transfer the project file.

Before disconnecting, open Project files and offline use and choose Make available offline. Wait for its confirmation. Keep a project file as a backup before clearing browser data.
