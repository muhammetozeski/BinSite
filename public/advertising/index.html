Advertising

Display advertisements can support free access to the tools and games. Advertising areas are labelled and kept separate from interactive controls.

Ad network status

Checking advertising configuration.

Google AdSense is the configured network option. Ads are loaded only after the publisher ID, ad unit, and required consent setup have been configured.

How ads appear

  • Ad units are labelled “Advertisement”.
  • Clicking an ad is never required to use a tool or finish a game.
  • Advertising code does not change an app's controls or place ads over the workspace.
  • Consent is handled by the approved publisher configuration where required.

For the site owner

The repository includes an AdSense configuration tool. Supply the approved publisher ID and ad unit, configure the required consent platform, then run the existing publication workflow. Private hosting credentials are not entered on this public page.
