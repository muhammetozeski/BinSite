From a product spreadsheet to a catalog someone can actually use

Catalog Studio turns product rows and local photos into a searchable HTML file or a printable catalog. The file you export includes its attached images and filtering controls, so you can hand it to another person without making them install an editor.

Open Catalog Studio

This guide follows one complete job: prepare five products, identify concrete data problems, connect the correct photos and export a usable file. Your local editing workflow needs no account or external service key.

1. Start with a small, explicit table

Each product needs a stable SKU, a name and a numeric price before it can be included in the final catalog. Use a separate column for category, stock, description and image filename. A SKU is the item's identifier; two different included items should not share it.

Download the five-product starter CSV. All items, prices and stock quantities in this file are fictional demonstration data. Replace them with your actual information before distributing a catalog.

SKU,Name,Price,Category,Stock
ST-101,Workshop Notebook,12.50,Stationery,24
ST-102,Desk Pencil Cup,9.00,Desk,18

Save your spreadsheet as a CSV file. A comma inside a description belongs inside a quoted field. A multiline description also needs quotes. The importer accepts comma, semicolon and tab separators, so a semicolon export from a spreadsheet does not need to be manually rewritten.

2. Map the columns instead of relying on their order

Open Import CSV and map its columns, choose your file or paste its text, then select Analyze CSV. Check the detected separator. Map your own headers to the editor's fields; a column named Item code can be used as SKU, and Retail amount can be used as price.

Select the price decimal convention that matches your data. 1234.50 and 1234,50 are different conventions; thousands separators should be removed first. A currency code labels the catalog's prices. It does not convert currency or calculate tax.

After checking the parsed preview, use Replace product rows with this import. Replacing rows is a deliberate operation. Save an existing project first if you want to keep its current contents.

3. Repair problems with evidence from the source rows

Download the deliberate repair exercise. It contains one repeated SKU, one missing name, a text price and a negative stock value. It is intended to produce real validation issues; it is not a clean export example.

ProblemWhy it mattersUseful repair

EX-003 has no nameThe item cannot be meaningfully presented.Enter its real product name.
EX-004 has a price of “ask”The price field is numeric.Enter the intended amount or exclude the row until it has one.

The editor retains source-row information so you can distinguish two similar entries. Search or filter the rows, select the intended group and use bulk editing only when the same change applies to every selected item. Excluding an unfinished product is different from repairing its values.

4. Connect actual photos to the intended items

Choose local PNG, JPEG or WebP files in the image bank. An exact image filename reference takes precedence. Otherwise a filename such as ST-101.jpg can match SKU ST-101. If two files could match one item, make the choice explicitly rather than trusting an ambiguous filename.

Inspect the displayed item and photo together. The tool creates resized local JPEG copies. A missing image produces a visible placeholder; the tool does not fetch an unrelated image and pretend it belongs to your product. Photo selection alone does not give you permission to distribute someone else's image.

5. Check the export you intend to send

The editor shows which included rows still block export. Repair or exclude those rows. Decide whether you want the whole included catalog or only the current search/category results. Then choose Download searchable standalone HTML.

Open that downloaded file and try a product name, a category and a search with no results. Use its print button when you need a paper or PDF snapshot. The print path waits for displayed images to decode; a broken image should be fixed by reattaching it and exporting again.

Keep an editable master

A searchable HTML catalog is a delivery artifact. Your JSON project is the editable master and can contain actual photo copies. Save it before closing the tab. Optional private cloud storage holds product metadata, not a hosted image collection; another device needs the matching originals or your complete JSON file to reconnect the photos.

Catalog Studio does not take an order, charge a customer or synchronize stock with a shop. Include your own valid ordering instructions in the catalog introduction when you need them. Update the source rows and re-export whenever the offer changes.
