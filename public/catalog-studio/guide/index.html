Build a searchable catalog

Import products, add photos and save a catalog people can search or print.

Open Catalog Studio

  1. Open a product list

    In Import CSV and map its columns, choose Open CSV. To paste a list, open Paste a list or change import options, then select Read this list.

  2. Check the columns

    Match Product code, Product name and Price, then select Use these products. Each included product needs a different code. If you change the column separator, select Read this list again. Set the price decimal separator in Catalog settings.

  3. Fix the marked rows

    Use Find row beside an issue. Edit its value, or untick Export to leave that product out. Edit details opens the description and photo choice. Excluded products stay in your project.

  4. Add photos

    Open Add photos (optional). Name a photo after its product code, such as ST-101.jpg, or choose it manually in Edit details. Use Match photos again for unmatched rows.

  5. Save the result

    Select Download catalog page (.html). Open that file to search it or choose Print results. Export only matching rows limits the catalog to your current filters. Use Save project file to keep the editable list and photos.

Moving or sharing your catalog

The catalog page includes its photos. Online project saves keep product details and filenames, not image files. Keep a project file with photos to continue editing on another device. Everyone invited to a shared catalog can read all its product text and filenames.
