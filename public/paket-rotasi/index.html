Dispatch guide

Each road square takes 1 minute and 1 fuel. Each van carries 3 packages. Load at the depot, add customers to each route in order, then dispatch. Both vans advance during the same minute.

Early vans wait for the delivery window. Deliveries consume the matching cargo. One late order ends the operation. You can reorder routes while vans are moving.

Every generated operation has a feasible schedule using both vans and the starting stock. Find a suitable order while dividing the cargo correctly.

Depot supplies

Load or unload vans only at the depot. Unloaded packages return to stock. Refuel at the depot. Extra purchases reduce your final budget score.
