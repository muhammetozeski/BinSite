Review a file revision

Mark changes on images or video and keep each note with the right version.

Open Client Review Room

  1. Open the files

    Choose Add images or videos, or Try an example to open one of three fictional review projects. Use Edit project details and Apply details to name your project.

  2. Mark a change

    Select a version. Click the image where the change belongs, or use Use image center. For video, pause at the frame and select Use this video frame. Write the note and choose Add comment.

    Example: “At this marker, replace the date with the supplied final date.” Choose Blocking change when it must be resolved before approval.

  3. Compare revisions

    Use Add a revised file to this delivery for a changed file. Old comments stay with the old version. Open Compare versions to read their notes and decisions. Use Go to comment to revisit its point or frame.

  4. Record the decision

    Use Mark ready for review, then Request changes or Record approval. Resolve blocking comments before approval. Record delivery follows approval; Reopen review allows another blocking change.

  5. Keep the feedback

    Open Project files and exports. Choose Save project file for editing later, Save review report for the review record, or Save open editing list for unresolved work.

Reopening or sharing a review

Project files and reports contain notes and decisions, not the media. Keep the original images/videos and choose Reconnect original files after reopening. Renamed originals can match; changed files belong in a new version.

Use Shared projects to save online and invite people. Everyone invited can read all notes. Send the matching media separately. If another editor saves first, keep a project file before reloading their changes.
