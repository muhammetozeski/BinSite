Quick workshop

1. Draw an object in the first frame.
2. Duplicate it and change a few pixels.
3. Build 4–8 frames and press Play.
4. Adjust the speed and bring the final frame close to the first for a continuous loop.

Use up to 48 frames. Stopping playback returns to the selected frame. The last 20 changes can be undone.
