How to use it

Choose a source, set start and end times, then add the selection. Reuse a source for multiple clips and reorder them with the arrows. Export writes 16-bit WAV samples, combining mono and stereo clips at one sample rate.

Each file may be up to 30 MB and must use a browser-supported format. Assembly is limited to ten minutes and uses local memory. Download before closing the tab.
