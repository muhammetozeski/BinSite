Place a ball and ramps, then set the chain reaction in motion.

In the example, a ball rolls down through three targets. Each target releases a new ball above it.

Help

Drawing rampsDrag from start to end. Balls bounce off segments and accelerate along slopes under gravity. Zero-length ramps are ignored.

Building a reactionClick to place balls and circular targets. Each target creates a new ball when hit and triggers only once.

An experiment toolTry the same layout with a small ramp change. Use up to 60 ramps, 12 starting balls and 20 targets.
