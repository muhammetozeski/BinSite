The current task was to read every existing UI source manually and remove irrelevant copy, duplicate actions and unclear controls. Source reviews cover the 75 catalog records, the two additional independent projects, shared pages/guides and the unpublished draft inventory. The 100 requested examples were delivered in chat. No automated keyword/source-search report replaced this reading.

Start with `review/manual-ui-index.md` and follow each product's source-reading report. `review/manual-ui-main-apps.md` records the source/build/live-browser boundaries and the successful BinSite publication at source commit `289fc7a`, workflow `40134036477`. The user-facing directory now provides one product-opening link per card, separates tools/games, and omits implementation feature lists. Product flows use short task descriptions and meaningful controls. Draft-preservation, stale-account and hidden-action issues found during the review were corrected. Project sources remain under the permanent WebSiteleri directory.

The unrelated pre-existing schema/community.sql working-tree change was not included. The broader target of 1,000 products and consolidation of the independent hosts remain unfinished; this release is the manual UI cleanup, not achievement of that broader goal.
