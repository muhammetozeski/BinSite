# Minimal-reading experience handover

This directory preserves the current context and lessons that affect continuing the project. It does not narrate Git history or duplicate the knowledge library. Read this guide once per new context, then choose records by filename before opening their contents.

Every meaningful result gets a new file named `yyyy.MM.dd HH.mm.ss - Meaningful subject and outcome.md`, using the actual Europe/Istanbul time of writing. Never overwrite a record with the same name. The newest record should briefly explain the overall current objective, relevant state and unresolved boundaries, so a contributor does not mistake the latest event for the whole project.

Describe the observation that changed the approach, the resulting action and verified outcome, and what the next contributor should do differently. Link to detailed knowledge rather than repeating it. Do not add empty forms, output dumps, apologies, invented history, unobserved successes or unexplained acronyms.

When resuming, list record names, read the newest context and latest relevant accumulation, then select newer and subject-specific experiences. Stop reading once purpose, current state and relevant lessons are clear. Read older details only to fill a specific gap. Do not search other projects, conversations or Git history to reconstruct unwitnessed events.

If too many records are needed to establish context, append a new dated accumulation with explicit coverage. Preserve still-relevant earlier lessons and decisions. Correct a disproved claim primarily in a new searchable record, stating the evidence; do not rewrite old records into a different history. An optional timestamped correction may be added to an already encountered old record without an archive-wide maintenance pass.

Use the smallest text that transfers the actual meaning. This economy applies to handover reading/writing, not a blanket limit on implementation quality. Verify only the new record's factual support and links; do not repeat unchanged tests merely to create a record.
