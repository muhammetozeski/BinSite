# Why this knowledge exists

BinSite combines independent web products, shared server functions, Blazor builds, and a publication pipeline. A future contributor should not rediscover how those boundaries interact or treat a proposed revenue model as an operating business. Knowledge documents preserve project-specific, supported explanations with the evidence and scope needed to use them again.

Keep each topic in one place and link to it from the index. A new fact is worth preserving when it removes real investigation or prevents repeating a demonstrated mistake. General platform tutorials belong in linked official documentation. Work chronology and pending tasks belong in Walkthrough, not this library.
